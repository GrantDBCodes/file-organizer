# 🗂️ File Organizer

A desktop application that automatically organizes files into category folders based on their file type.

## What It Does

Select any folder and the app will sort your files into organized categories:

| Category | File Types |
|---|---|
| Images | .jpg, .jpeg, .png, .gif |
| Music | .mp3, .wav |
| Videos | .mp4, .avi |
| Documents | .pdf, .docx, .xlsx, .txt |
| Archives | .zip, .rar, .7z, .tar |
| Torrents | .torrent |

## Built With

- Python
- tkinter (GUI)

## How To Run

1. Make sure Python is installed
2. Clone this repo
3. Run `python organizer_gui.py`
